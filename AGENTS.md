# CanDuru4

GitHub profile README for the `CanDuru4` account. GitHub renders `README.md` on the profile page, so the repo is public and holds nothing else: no code, no build, no tests, no deploy. A merge to `main` publishes the change on the profile.

## Editing the README

- Edit `README.md` only, through a branch and pull request (`main` is the published branch).
- Public and factual: every claim, role, employer, number and link must trace to something the owner stated or a public page. Do not add an unsourced claim; ask first.
- Tone is plain and consistent: no emoji and no email address (a cleanup removed both).
- Link only to repositories and pages that exist and are public; check each link before keeping or adding it.
- Wording the owner requires: "LotusAI" is one word, say Wharton and finance (never Entrepreneurship), keep Intern in role titles, and do not describe any degree beyond the current undergraduate program as completed.
- The page uses HTML (`<h1 align="center">`, icon links) and Markdown together; keep that structure unless the owner asks for a redesign.

## Data and secrets

Public repo: no secrets, tokens, internal paths or private project details in any file, including this one.
